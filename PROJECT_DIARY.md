# 📘 GUIDANCE Project Diary

## 🎨 Backend & Frontend Architecture

### 1. The Aesthetic: "Cyber-Glass"
The entire application follows a strict **Dark Mode + Neon Lime** design system inspired by Apple's Glassmorphism but with a high-contrast developer twist.

*   **Primary Accent:** `Neon Lime (#ccff00)` - Used for calls-to-action, active states, and confidence indicators.
*   **Background:** `Deep Black (#000000)` and `Dark Gray (#1c1c1e)` for cards.
*   **Materiality:** Extensive use of `backdrop-blur-xl` (20px+ blur) to create a frosted glass effect on panels, making the UI feel layered and depth-filled.
*   **Motion:** `Framer Motion` powers all transitions, giving a "fluid" feel to page loads and hover states.

## 🎙️ Voice & AI Agents

### 2. Career Guide ("Guido Assistant")
**Purpose:** A conversational mentor for general career advice.
*   **Frontend:** `SpeechRecognition` API (Web Standard) for listening; `SpeechSynthesis` for speaking.
*   **Backend:** `CareerAdviceView` (Django).
*   **Intelligence:** 
    *   **Brain:** Llama 3.1 (via Groq API) for instant responses.
    *   **Voice:** EdgeTTS (Microsoft Edge's Neural Voice API) for high-quality, natural-sounding speech (English & Malayalam).
*   **Unique Feature:** Detects strict "Identity Rules" to ensure it never breaks character as a mentor.

### 3. Interview Coach ("AI Interview Studio")
**Purpose:** Real-time interview simulation with visual feedback.
*   **Vision Engine:** **MediaPipe FaceLandmarker** runs entirely in the browser (Client-Side).
    *   **Posture Check:** Calculates the nose-tip vector. If it strays outside the normalized box `(0.35-0.65, 0.3-0.7)`, it flags a posture violation in real-time (<10ms latency).
*   **Analysis Engine:** **Hybrid Architecture**.
    *   While video is processed locally, the *content* of answers is sent to the backend.
    *   The backend uses **Llama-3.3-70b** to grade answers on a 1-10 scale and rewrite them professionally.
*   **Reporting:** Generates a PDF report using `ReportLab` that is streamed directly to the client as a binary blob.

## 📊 Data Intelligence

### 4. Job Insights Engine
**Purpose:** Finding relevant software jobs without the noise.
*   **Data Source:** **Remotive API** (Live remote job feed).
*   **Scoring Algorithm:** Custom weighted ranking:
    *   `+40 pts`: Role Title Match (e.g., "Backend").
    *   `+40 pts`: Tech Stack Keyword Match (e.g., "Django", "React").
    *   `+20 pts`: Location Compatibility.
*   **Market Intelligence Agent:**
    *   A searchable "Hero Card" that uses **Gemini 1.5 Flash** to generate instant market reports (Salary, Trends, Skills) for any query.
    *   Uses `localStorage` caching to prevent redundant API calls.

### 5. LinkedIn "Deep Link"
**Purpose:** Seamless transition to social networking.
*   **Strategy:** Stateless integration.
*   **Mechanism:** `window.open` with dynamic query injection:
    `https://www.linkedin.com/search/results/all/?keywords=${encodeURIComponent(query)}`
*   **Benefit:** Zero-auth, privacy-preserving way to connect users to real recruiters.

## 🧩 Gamified Learning

### 6. Code Helper ("LogicQuest")
**Purpose:** Teaching logic before syntax.
*   **Core Logic:** `MicroProblemView` (Django).
*   **Content Source:** Hybrid.
    *   **Dataset:** Processed LeetCode CSV (2000+ problems).
    *   **Seed:** Curated JSON for fallback.
*   **The "Gamifier" Agent:**
    *   Uses **Llama 3.1 8B** with a specific persona ("LogicQuest AI") to rewrite standard coding problems into RPG "Quests".
    *   *Example:* A "Reverse String" problem becomes "The Mirror Spell" in the "Scrolls of String" realm.
*   **Pedagogy:** Forces the user to write *pseudocode/logic* first before showing the actual Python/SQL solution.
